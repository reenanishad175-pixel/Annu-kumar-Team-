# Color Prediction Bot

Android Kotlin application prototype.

- Four strategy rule definitions are documented in project requirements.
- BDG WebView and local Telegram settings screens are included in this initial build scaffold.
- No subscription, activation, admin, or in-app payment flow.
- Build: GitHub Actions workflow `.github/workflows/android-build.yml`.

Important: the BDG page's live period/result extraction and Telegram message automation are not yet implemented or verified in this scaffold. Prediction output must not be treated as live until those integrations are tested.
